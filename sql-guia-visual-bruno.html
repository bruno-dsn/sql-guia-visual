SQL no Aeroporto de Dados

Aprenda SQL do zero usando um sistema real de voos como exemplo. Cada comando é uma ferramenta que o controlador de tráfego usa para gerenciar o aeroporto.

SELECT

O painel de informações do aeroporto

Escolha exatamente quais dados você quer ver — como configurar quais telões exibir no saguão. Você pode pedir todas as colunas ou selecionar apenas as que importam.

↑ Todas as linhas retornadas pelo SELECT *

Exemplo 1 — Selecionar tudo
query_01.sql 
SELECT *
FROM voos;
-- * = todas as colunas
Exemplo 2 — Colunas específicas
query_02.sql 
SELECT destino, companhia, hora
FROM voos;
-- Só 3 colunas, sem id/status/gate
query_03.sql — alias 
SELECT
  destino        AS "Cidade de Destino",
  hora           AS "Horário de Saída",
  gate           AS "Portão"
FROM voos;
-- AS renomeia a coluna no resultado
💡
Dica profissionalUse SELECT * apenas para explorar dados. Em produção, liste as colunas — melhora performance e clareza do código.
📖 Variações do SELECT
SELECT DISTINCT
Remove duplicatas — mostra só valores únicos de uma coluna.
SELECT TOP / LIMIT
Limita o número de linhas retornadas. LIMIT 10 traz só 10 registros.
SELECT coluna AS apelido
Renomeia a coluna no resultado sem alterar o banco de dados.
SELECT expr calculada
Você pode calcular direto: SELECT preco * 1.1 AS com_taxa.
WHERE

O filtro do controlador de tráfego

Retorna apenas os registros que atendem a uma condição — como o controlador que só quer ver no radar os voos atrasados ou cancelados.

filtro básico
SELECT destino, companhia
FROM voos
WHERE status = 'Atrasado';
-- Resultado: só Rio de Janeiro / Gol
AND e OR
-- AND: ambas condições precisam ser true
WHERE status = 'Atrasado'
  AND companhia = 'Gol'

-- OR: pelo menos uma condição
WHERE status = 'Cancelado'
  OR  status = 'Atrasado'
IN e BETWEEN
-- IN: lista de valores aceitos
WHERE companhia IN ('LATAM', 'Gol', 'Azul')

-- BETWEEN: intervalo (inclusivo)
WHERE hora BETWEEN '08:00' AND '10:00'

GROUP BY

O relatório por companhia aérea

Agrupa linhas com o mesmo valor e permite calcular totais, médias e contagens por grupo — como o gestor contando quantos voos cada companhia opera hoje.

contar voos por companhia
SELECT
  companhia,
  COUNT(*) AS total_voos
FROM voos
GROUP BY companhia;
-- Cada companhia vira uma linha
GROUP BY + HAVING (filtro de grupo)
SELECT
  companhia,
  COUNT(*) AS total_voos
FROM voos
GROUP BY companhia
HAVING COUNT(*) >= 3;
-- HAVING filtra após o agrupamento
-- WHERE filtra antes — não confunda!

📌
Regra de ouro do GROUP BYToda coluna no SELECT que não é uma função de agregação (COUNT, SUM, AVG, MAX, MIN) precisa aparecer no GROUP BY. Se não aparecer, o banco vai retornar erro.
🔄 WHERE vs HAVING — quando usar cada um?
WHERE
Filtra linhas individuais antes do agrupamento.
Não pode usar funções de agregação aqui.
HAVING
Filtra grupos depois do agrupamento.
Pode (e deve) usar COUNT, SUM, AVG etc.
ORDER BY

A fila de embarque organizada

Ordena os resultados da forma que você quiser — do mais cedo ao mais tarde, por nome alfabético, pelo maior atraso. Você decide a direção: ASC (crescente) ou DESC (decrescente).

ordem crescente (padrão)
SELECT hora, destino
FROM voos
ORDER BY hora ASC;
-- ASC é o padrão (pode omitir)
múltiplas colunas
SELECT companhia, destino, hora
FROM voos
ORDER BY
  companhia ASC,
  hora      ASC;
-- Primeiro ordena por companhia,
-- depois por hora dentro de cada uma
com LIMIT — top 3
SELECT destino, atraso_min
FROM voos
ORDER BY atraso_min DESC
LIMIT 3;
-- Os 3 voos com maior atraso

  COUNT(*)              AS total_voos,
  COUNT(gate)           AS com_gate,
  AVG(atraso_min)       AS media_atraso,
  MAX(atraso_min)       AS maior_atraso,

🔎
COUNT(*) vs COUNT(coluna)COUNT(*) conta todas as linhas incluindo NULLs. COUNT(coluna) ignora NULLs — conta só onde tem valor.
funções com GROUP BY
SELECT
  companhia,
  COUNT(*)         AS total_voos,
  AVG(atraso_min)  AS media_atraso,
  SUM(passageiros) AS total_pass
FROM voos
GROUP BY companhia
ORDER BY total_voos DESC;

Subquery

Uma consulta dentro da outra

Uma subquery é um SELECT dentro de outro SELECT — como pedir ao sistema: "me dê os voos com atraso acima da média do dia." A pergunta interna calcula a média; a externa filtra usando esse resultado.

subquery no WHERE
-- Voos com atraso acima da média
SELECT destino, atraso_min
FROM voos
WHERE atraso_min > (
  SELECT AVG(atraso_min)
  FROM voos
);
-- A parte em () é executada primeiro
-- Calcula a média → depois filtra
subquery no FROM (tabela derivada)
SELECT companhia, total_voos
FROM (
  SELECT
    companhia,
    COUNT(*) AS total_voos
  FROM voos
  GROUP BY companhia
) resumo
WHERE total_voos >= 3;
-- "resumo" é um nome para a subquery
🧩 Como funciona a subquery
1️⃣
Consulta interna executa primeiro
SELECT AVG(atraso_min) FROM voos → retorna 18
↓
2️⃣
Consulta externa usa o resultado
WHERE atraso_min > 18 → filtra os voos
Resultado: voos acima da média (18 min)

💡
Quando usar CTE (WITH) no lugar de subqueryPara subqueries complexas ou reutilizadas, prefira CTE:
WITH resumo AS (SELECT ...) SELECT * FROM resumo. É mais legível e fácil de depurar.
✅ Boas Práticas

Como escrever SQL de qualidade

Saber a sintaxe é o começo. Escrever SQL claro, eficiente e fácil de manter é o que diferencia um analista de dados sênior.

✍️ Formatação e legibilidade
❌ difícil de ler
select id,nome,companhia from voos where status='Atrasado' and hora>'09:00' order by hora;
✅ limpo e organizado
SELECT
  id,
  nome,
  companhia
FROM  voos
WHERE status = 'Atrasado'
  AND hora   > '09:00'
ORDER BY hora;
